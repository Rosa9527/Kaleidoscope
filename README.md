# 万华镜（Kaleidoscope）

一套基于 LLM 的动态叙事引擎的 SillyTavern / TauriTavern 插件（当前版本 v0.5.0）。

> 万华镜允许作者将预先设计好的剧情、世界观、事件节点等内容以多层级文件结构进行组织，
> 在运行时由 AI 根据当前对话状态、角色行为和剧情进展，自动分析并选择需要读取的剧情模块，
> 将相关内容动态注入上下文，从而实现非线性的剧情推进。

## 当前版本（v0.5.0）包含

- **六棱万花筒悬浮球**：可拖拽、点击打开面板、长按隐藏；古风典雅主题（宣纸 + 墨色 + 朱砂 + 鎏金）。
- **API 连接**：Base URL / API Key / 拉取模型列表 / 手动填模型 / 并发限制 / 思考强度；
  支持跨域走宿主代理并自动回退直连（SillyTavern 与 TauriTavern 通用）。
- **扩展菜单入口**：宿主 API 注册 + 手动注入双保险，菜单自愈。
- **剧情脉络（可视化工作台）**：全屏遮罩 + 大窗口的树状工作台（手机端为面板内视图，与其它功能一致）；
  一套结构通吃两种典型用法——**规则 / 常驻触发**（节点组织场景 / 状态，如「日常」→「房间」→「睡眠」，
  事件 `trigger` 写触发时机，如「日常时」「进入房间」「睡觉前」）与**剧情叙事**
  （节点组织卷 / 章，如「第一卷」→「第一章」，`trigger` 写推进条件）；
  事件（skill 式模块）挂在任意节点下，未分类事件单独成组；
  支持新建 / 编辑 / 删除节点与事件、节点下新建或导入事件、整包 YAML 导入/导出
  （文件格式与编写方法见 [`剧情脉络书写指南 1.0.0.md`](剧情脉络书写指南 1.0.0.md)）、
  单事件 frontmatter（`--- name / id / Trigger / description ---`）导入/导出与在线编辑，事件 ID 默认 001 起自动递增、重复时自动顺延；
  整包导入可选择**合并**（同 id 更新、其余追加）或**覆盖**（清空后整体替换），节点行滑块可随时停用/激活整棵子树（不再参与预筛）；删除节点时子节点上移、事件转未分类（不误删）。
- **剧情脉络 · 角色卡绑定**：剧情数据（节点 + 事件）保存在角色卡内（`data.extensions.kaleidoscope_story`，
  参考 SillyTavern 局部正则脚本）——导入角色卡时剧情脉络自动随卡进入插件，导出角色卡时一并导出；
  **剧情脉络只显示当前角色卡绑定的内容**，切换到没有绑定文件的角色卡时显示为空；
  工作台头部显示绑定徽标（已绑定 / 待绑定 / 未绑定角色），旧版全局数据在首次变更时自动迁入当前角色卡；
  群聊 / 未选角色时回退全局设置，宿主不支持写角色卡时自动降级；
  「导出 剧情脉络」直接导出当前角色卡的剧情脉络文件（`剧情脉络: 角色卡名.yaml`，
  文件含 `format: kaleidoscope-story` 标记与角色卡名，导入时自动识别并在确认框提示来源）。
- **系统日志**：面板内日志视图（参考 SoulLink 实现）——捕获 console、页面错误、Promise 拒绝、
  宿主事件与 fetch 网络请求，支持级别/来源/搜索过滤、暂停、跟随、清空、复制、导出（含最近 5 次完整请求体/响应体）与噪音过滤；
  对外暴露 `KaleidoscopeLog` API，热重载不丢缓冲。
- **首页**：镜鉴英雄区 + 功能卡片（API 连接、剧情脉络、系统日志、注入实录）。
- **对话请求基础**：`chatCompletion`（OpenAI 兼容，超时 / 重试 / 并发限制），供后续叙事引擎使用。
- **剧情预筛（Story Gate）**：点击发送时阻塞预筛——AI 读取剧情脉络（节点与事件的名字 / ID / 触发条件 / 描述，不含正文）与最近 4 条消息，按约定 JSON 输出本轮应触发的事件 ID；系统把事件正文以 `<Story_Event>` 块注入最后一条用户消息正下方，生成结束后自动清理。参考 SoulLink 角色预筛 Gate 的稳定性设计：运行锁 + 签名去重、messageSent 载荷校验（文本 / 消息 ID 与末条消息一致，防其他插件误触发）、主生成配对（无生成在途的 messageSent 直接跳过）、名单交集、失败即降级放行、总超时硬截止。预设模版可开关并编辑预筛提示词（留空用默认）。
- **跨扩展发送屏障**：与 SoulLink 共用发送屏障协议（`globalThis.__preSendInjectionBarrier__`）——
  两个扩展的发送前预筛任务并发执行，发送前耗时从「各 Gate 之和」降为「各 Gate 最大值」，
  且保证两个注入都在主请求发出前完成；任一扩展失败 / 超时都不阻塞发送，屏障不可用时各自回退。
- **注入实录**：面板内详情视图（参考 SoulLink「角色扮演」视图）——展示最近一轮剧情预筛的完整结果：预筛原文（Gate 返回）、本轮触发的事件（名称 / ID / 触发条件 / 说明 / 正文）、最终注入上下文的 `<Story_Event>` 提示词原文（可一键复制）；首页「注入实录」卡片点击进入。

## 开发与构建

改 `js/` 下的源码，**不要手改 index.js**；构建产物会被覆盖。

```bash
node build.js          # 一次性构建
node build.js --watch  # 监听 js/ 变更自动重建
```

改完构建后重启酒馆（或热重载扩展）即可生效。

数据层与工作台 UI 有自动化测试（jsdom，仅开发用）：

```bash
node tests/data.test.js   # 数据层：层级 / 防环 / 删除上移 / YAML 往返 / 角色卡绑定
node tests/ui.test.js     # UI：打开工作台 / 建节点 / 建事件 / 导入导出 / 删除 / 绑定徽标
node tests/gate.test.js   # 剧情预筛：目录 / Gate 消息 / 解析 / 注入 / 管线
```

## 宿主差异说明

- TauriTavern 的 manifest 只接受单个 JS 文件，因此源码拆在 `js/` 下、构建时拼接。
- 事件订阅统一经 `host.js` 适配（`ctx.event_types` 解析 + 事件源自愈看门狗）。
- 跨域 API 请求自动走宿主代理：对话用 `/api/backends/chat-completions/generate`（TauriTavern 专用接口），模型列表探测用 `/api/backends/chat-completions/status`；代理明显损坏（非 JSON / 无内容 / 路由不存在）时回退直连。
