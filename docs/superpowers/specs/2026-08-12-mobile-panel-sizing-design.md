# 移动端面板分级尺寸设计

日期：2026-08-12

## 目标

修正 SillyTavern 手机端的面板尺寸策略：

- 「剧情脉络」继续作为独立工作台，适应性铺满手机视口。
- 首页保持紧凑浮窗，不用过大的面板遮挡对话。
- API 连接使用中等大小的浮窗，保证表单和操作按钮有足够空间。
- 系统日志、预设模版、注入实录使用较大的浮窗，给长内容和编辑区更多空间，但仍保留手机屏幕边距、圆角和阴影，不做真正的全屏覆盖。
- 桌面端现有尺寸、拖拽和视图行为保持不变。

## 根因

当前 `style.css` 的移动端媒体查询直接对所有 `.kaleido-panel__dialog` 设置 `left/top/right/bottom: 0`、`width: 100vw`、`height: 100dvh`，因此首页、API 连接、系统日志、预设模版、注入实录全部变成全屏。

「剧情脉络」不依赖这个面板容器，而是使用独立的 `.kaleido-story-dialog` / `.kaleido-story-dialog__inner`。因此应保留工作台的全屏规则，收窄普通面板的移动端覆盖范围。

## 设计

### 1. 视图尺寸模式

面板在切换视图时给对话框同步一个轻量的尺寸模式类。模式只用于移动端 CSS，桌面端不改变现有宽视图类和定位逻辑。

| 视图 | 模式 | 手机端策略 |
| --- | --- | --- |
| 首页 | `is-home-mode` | 紧凑浮窗；约 16px 外边距；宽度上限约 360px；高度随内容自适应并受视口上限约束 |
| API 连接 | `is-api-mode` | 中等浮窗；约 14px 外边距；适应表单高度 |
| 系统日志 | `is-log-mode` | 大浮窗；约 10px 外边距；使用大部分可用高度，日志列表继续内部滚动 |
| 预设模版 | `is-preset-mode` | 大浮窗；约 10px 外边距；使用大部分可用高度，提示词编辑区获得足够空间 |
| 注入实录 | `is-inject-mode` | 大浮窗；约 10px 外边距；适合较长的预筛与注入内容 |
| 剧情脉络 | 独立工作台 | 保持现有 `100vw × 100dvh` 移动端工作台，不套用普通面板尺寸模式 |

普通面板的“大”指保留可见边距的浮窗，而不是取消边框、圆角或阴影。浮窗对话框的 top/bottom 本身按安全区偏移（避免刘海与底部手势条遮挡）；标题栏不再叠加顶部安全区（否则「万华镜」标题上方会出现大块空白），主体与页脚保留底部安全区内边距。

### 2. 视图切换与定位

- 在 `showPanelView` 中统一移除旧的尺寸模式类，再添加当前视图模式类，避免从预设模版返回首页时沿用大尺寸。
- 手机端默认位置由 CSS 模式控制；用户拖动标题栏后（与桌面端一致，同 SoulLink），
  面板进入 `is-user-positioned` 状态，改由内联 left/top 接管并保留在视口内。
- 首页采用居中的紧凑卡片；其他普通面板采用固定安全边距的大卡片。切换视图时不修改数据、不重建内容，只改变容器样式。
- 「剧情脉络」的 ESC 优先级、编辑器覆盖层和独立遮罩逻辑不变。

### 3. 内容溢出与交互

- 普通面板主体继续使用现有纵向滚动容器；日志列表、预设文本区、注入内容等内部滚动规则不改变。
- 现有手机端 16px 表单字号、触控目标放大、安全区 padding 和 overscroll 规则继续保留。
- 不新增设置项，不改变宿主 API、数据存储、事件订阅或构建流程。

## 测试策略

1. 增加 UI 回归断言：切换首页、API、日志、预设、注入视图时，对话框只保留对应的尺寸模式类，不残留上一个视图的模式。
2. 增加静态布局回归检查：普通面板的移动端规则包含分级模式，剧情工作台仍包含全屏规则；避免以后重新出现统一全屏覆盖。
3. 运行现有数据、UI、代理、剧情预筛、发送屏障和构建一致性测试。
4. 使用手机视口至少检查 346×778：
   - 剧情脉络覆盖完整视口；
   - 首页明显保留较大边距；
   - API 连接可完整显示主要表单；
   - 日志、预设模版、注入实录有边框和圆角，同时内部内容可滚动；
   - 不出现横向溢出、按钮裁切或视图切换后尺寸残留。
5. 使用默认桌面视口复查面板宽度、拖拽定位和剧情工作台未发生回归。

## 验收标准

- 只有「剧情脉络」在手机端真正铺满屏幕。
- 首页、API 连接、系统日志、预设模版、注入实录均保留浮窗边距；其中首页最紧凑，预设模版及长内容视图明显更大。
- 在不同视图之间来回切换，尺寸模式始终与当前视图一致。
- 桌面端现有体验与所有现有自动化测试不受影响。
