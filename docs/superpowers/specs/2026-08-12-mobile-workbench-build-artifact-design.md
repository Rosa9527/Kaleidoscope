# 移动端剧情脉络工作台构建产物修复设计

日期：2026-08-12

## 目标

修复 SillyTavern 手机端实际加载旧版 Kaleidoscope 脚本导致的剧情脉络工作台显示异常，使宿主加载包含 v0.7.5 移动端适配的构建产物。

## 已确认的根因

- `manifest.json` 的 `js` 字段指向 `index.js`。
- 源码 `js/constants.js` 与 `manifest.json` 已经是 v0.7.5。
- `index.js` 仍保留 v0.7.4，且该文件最后一次提交早于 v0.7.5 修复提交。
- 用户截图底部显示 `v0.7.4`，与实际加载旧构建产物相吻合。
- 仓库开发约定要求通过 `node build.js` 生成 `index.js`，不直接手改构建产物。

因此本次问题的根因是构建产物没有随 v0.7.5 源码更新，而不是需要继续调整工作台布局 CSS。

## 方案

1. 保持 `js/` 源码与 `manifest.json` 为版本来源。
2. 新增轻量构建一致性测试，读取 `manifest.json`、`js/constants.js` 和 `index.js`，断言三者版本一致。
3. 先运行该测试确认当前 v0.7.4 构建产物会按预期失败。
4. 运行现有 `build.js` 重新生成 `index.js`，不修改工作台业务逻辑。
5. 运行一致性测试、全量自动化测试，并在 346×778 手机视口复查工作台。

## 变更范围

- 新增构建产物一致性回归测试。
- 更新生成的 `index.js`。
- 不改动工作台的 DOM、CSS、数据模型或交互逻辑。
- 保留工作区中与本任务无关的用户文件，不纳入提交。

## 验收标准

- 一致性测试通过，且 `manifest.json`、`js/constants.js`、`index.js` 都报告 v0.7.5。
- 现有 data、UI、proxy、gate、barrier 测试全部通过。
- 移动端工作台打开后覆盖视口，树行名称可见，操作按钮不被裁切，页面无横向溢出。
- 实际加载版本不再显示 v0.7.4。
